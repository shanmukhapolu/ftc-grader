# FTC Grader

AI-assisted engineering portfolio and presentation evaluation against competition-specific manuals and judging rubrics.

This project uses React + Vite, PDF/PPTX text extraction in the browser, and a server-side Netlify Function that calls OpenRouter. The OpenRouter API key must be configured as a Netlify Functions environment variable named `OPENROUTER_API_KEY`; never commit secrets.

See the application setup instructions as the project is developed.
